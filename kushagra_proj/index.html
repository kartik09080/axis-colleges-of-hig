Axis Drive needs its Python server

Axis Drive is a cloud storage app (login, uploads, photos, share links, trash). It needs a server to store your files, so it cannot run on GitHub Pages.

To run it on your computer: double-click start-drive.bat (Windows) or start-drive.command (Mac), or run ./start-drive.sh (Linux). Then open http://localhost:8000.

To run it on the cloud: deploy this folder with the included Dockerfile or render.yaml. See README.md for the steps.
